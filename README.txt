STUDIOS ROYAL9 — WEBSITE ZIP

The site/ folder contains the production-built website. Upload the contents of
that folder to a static web host, or serve it over HTTP locally. Because this
site uses client-side routes, configure the host to serve index.html for
unknown paths so routes such as /portfolio, /films, and /contact work on refresh.

Images and Instagram posts are loaded from their public services and require an
internet connection. This ZIP contains the compiled site, not installed packages.
